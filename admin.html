How to use this panel

Adding a project / gallery item

Click the + Add new button on the relevant tab, fill the form, and hit Save. Changes appear on the site immediately when you refresh it.

Uploading gallery photos

Option 1 (easiest): Upload your photo to a free host like imgur.com or postimages.org, copy the direct image URL, and paste it into the "Image URL" field.
Option 2: Use the Choose file button to upload a small photo directly (best under 500KB — larger photos slow the site down).

Data is stored in this browser

Changes only apply to this browser, on this device. Use Export to back up your work, and Import to load it on another device. If you clear browser data, you'll lose changes — that's why exporting is important.
